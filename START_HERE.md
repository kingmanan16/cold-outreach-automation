# Start here: put this project on your GitHub using Cursor

You don't need to know Git. Cursor's AI does all the setup. It will install anything that's missing,
connect your GitHub account, create the repository and upload the code.

## What you need
- **Cursor** installed (https://cursor.com)
- A **GitHub account**. If you don't have one, make a free account at https://github.com/signup
  (or let Cursor walk you through it).

## Steps

1. **Extract the zip** anywhere, for example your Desktop or Documents.
2. **Open Cursor → File → Open Folder…** and choose the extracted folder
   `Cold_Outreach_Automation-main` (the one that contains `package.json` and this file).
3. Open the AI chat (**Ctrl + L** on Windows, **Cmd + L** on Mac) and make sure the mode is set to **Agent**
   (not "Ask"), so it can run commands.
4. Copy and paste this message into the chat:

   ```
   Read the file CURSOR_GITHUB_SETUP.md in this project and carry out every step in it,
   in order, from start to finish. Run the terminal commands yourself and only stop to
   ask me when the file says to. I'm new to Git, so explain each step in one simple sentence.
   ```

5. Follow along. Cursor will ask you a few things:
   - to **approve running commands** (click *Run* / *Accept*),
   - to **log in to GitHub**: it shows a short code in the terminal, the browser opens, you paste the code
     and click **Authorize**,
   - for a **repository name** and whether it should be **private** (recommended).

When it's finished, Cursor will give you the link to your new GitHub repository. 🎉

**Tip:** if Cursor ever gets stuck after installing something, close the terminal, open a new one
(Terminal → New Terminal) and tell Cursor "continue".
